# Marketing Analytics Dashboard

A simplified Google Analytics dashboard built with Next.js, designed to make website analytics more accessible and easier to understand for businesses of all sizes.

## 🚀 Features

- **Simplified Analytics**: Clean, easy-to-understand dashboard interface
- **Real-time Data**: Direct integration with Google Analytics API
- **Secure Authentication**: OAuth 2.0 with Google
- **Mobile Responsive**: Works perfectly on all devices
- **No Data Storage**: Your analytics data stays with Google
- **Multiple Properties**: Support for multiple Google Analytics properties
